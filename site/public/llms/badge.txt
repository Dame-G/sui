# Badge

Stamp for status: a tinted chip with a tone-coloured side slab.

Group: Primitives. Registry item: http://localhost:5173/r/badge.json

## Install

```sh
bunx shadcn-vue@latest add http://localhost:5173/r/badge.json
```

Installs with: theme, utils. npm packages: none beyond Vue.

Import it from your own copy: `import Badge from '@/components/ui/badge.vue'`.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `tone` | `'neutral' \| 'info' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` |  |

Slots: `default`.

## Usage

```vue

import Badge from '@/components/ui/badge.vue'
</script>

<template>

```

## Rules

- Style it through theme tokens, not classes: sui has one design per component and no variants. `tone` exists only on status components.
- You own the copy: edit the file if the design must change.
