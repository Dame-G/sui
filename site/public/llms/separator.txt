# Separator

Hairline rule, horizontal or vertical.

Group: Primitives. Registry item: http://localhost:5173/r/separator.json

## Install

```sh
bunx shadcn-vue@latest add http://localhost:5173/r/separator.json
```

Installs with: theme, utils. npm packages: reka-ui.

Import it from your own copy: `import Separator from '@/components/ui/separator.vue'`.

## Props

No props; it takes content only.

Also takes everything in SeparatorProps, and `class` for placement only.

## Usage

```vue
<script setup lang="ts">
import Separator from '@/components/ui/separator.vue'
</script>

<template>
  <div class="grid gap-8">
    <div class="flex max-w-sm flex-col gap-3">
      <p class="kicker">Horizontal</p>
      <span>Above the rule</span>
      <Separator />
      <span>Below the rule</span>
    </div>
    <div class="flex flex-col gap-2">
      <p class="kicker">Vertical</p>
      <div class="flex h-6 items-center gap-3"><span>Docs</span><Separator orientation="vertical" /><span>Blog</span><Separator orientation="vertical" /><span>Changelog</span></div>
    </div>
  </div>
</template>
```

## Rules

- Style it through theme tokens, not classes: sui has one design per component and no variants. `tone` exists only on status components.
- You own the copy: edit the file if the design must change.
