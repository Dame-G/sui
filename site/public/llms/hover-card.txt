# Hover card

Rich preview shown when hovering a link or trigger.

Group: Overlays. Registry item: http://localhost:5173/r/hover-card.json

## Install

```sh
bunx shadcn-vue@latest add http://localhost:5173/r/hover-card.json
```

Installs with: theme, utils. npm packages: reka-ui.

Import it from your own copy: `import Hovercard from '@/components/ui/hover-card.vue'`.

## Props

No props; it takes content only.

Slots: `trigger`, `default`.

## Rules

- Style it through theme tokens, not classes: sui has one design per component and no variants. `tone` exists only on status components.
- You own the copy: edit the file if the design must change.
