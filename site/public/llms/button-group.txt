# Button group

Buttons joined into one control with matching corners.

Group: Primitives. Registry item: http://localhost:5173/r/button-group.json

## Install

```sh
bunx shadcn-vue@latest add http://localhost:5173/r/button-group.json
```

Installs with: theme, utils. npm packages: none beyond Vue.

Import it from your own copy: `import Buttongroup from '@/components/ui/button-group.vue'`.

## Props

| Prop | Type | Default | What it does |
| --- | --- | --- | --- |
| `orientation` | `'horizontal' \| 'vertical'` | `'horizontal'` |  |

Slots: `default`.

## Usage

```vue
<script setup lang="ts">
import Button from '@/components/ui/button.vue'
import ButtonGroup from '@/components/ui/button-group.vue'
</script>

<template>
  <div class="flex flex-wrap items-start gap-x-12 gap-y-8">
    <div class="flex flex-col gap-2">
      <p class="kicker">Horizontal</p>
      <ButtonGroup>
        <Button>Day</Button>
        <Button>Week</Button>
        <Button disabled>Month</Button>
      </ButtonGroup>
    </div>
    <div class="flex flex-col gap-2">
      <p class="kicker">Vertical</p>
      <ButtonGroup orientation="vertical">
        <Button>Top</Button>
        <Button>Middle</Button>
        <Button>Bottom</Button>
      </ButtonGroup>
    </div>
  </div>
</template>
```

## Rules

- Style it through theme tokens, not classes: sui has one design per component and no variants. `tone` exists only on status components.
